# 截图清单（12 张）

> 助教作业帖要求博客提供「**10 张以上截图或 GIF / 视频**，每张配一句文字说明」。
> 本清单就是那份说明的来源，博客里可直接引用。
>
> 生成方式：`node tools/capture-screens.mjs` —— **可复现**，不是手点出来的。
> 每张截图在生成前都会校验页面确实渲染出了目标表达式，校验不通过就直接报错终止，
> 因此不会出现"图与说明不符"的情况。

| # | 文件名 | 一句话说明 |
|---|---|---|
| 1 | `01_初始界面.png` | 打开页面后的默认状态：深色两栏布局，左侧计算器、右侧历史记录区。显示屏显示占位提示，右下角如实标注「后端未启用 · 结果由后端计算」 |
| 2 | `02_加法.png` | 逐键输入 `12+8`。表达式行实时回显，`+` 键高亮表示它是当前生效的运算符 |
| 3 | `03_减法.png` | 减法 `9-4`。界面显示 `−`，内部保存 ASCII 减号，交给后端时无歧义 |
| 4 | `04_乘法.png` | 乘法 `5×8`。界面用 `×` 显示、内部记 `*` —— 显示与数据分离，不把界面符号塞进表达式 |
| 5 | `05_除法.png` | 除法 `10÷2`，同样界面 `÷`、内部 `/` |
| 6 | `06_小数计算.png` | 小数 `3.5+1.25`。规则限制同一个数字里只能有一个小数点 |
| 7 | `07_复合表达式.png` | 复合表达式 `1+2×3`：运算优先级由后端负责，前端只如实呈现用户输入 |
| 8 | `08_括号.png` | 括号 `(1+2)×3`。括号必须配对，且右括号前必须是数字 |

| 12 | `12_除零错误提示.png` | 除法 `10/0`。除零由**后端**判定，前端把后端返回的 `DIVISION_BY_ZERO` 翻译成中文「除数不能为 0」并标红 |

## 如何复现

```powershell
cd "D:\calss notes\软件工程\作业\计算器\832401217_calculator_frontend"
node tools\capture-screens.mjs
```

脚本自动完成：复制 `src/` 到临时目录 → 为每张图设置状态 → 启动无头 Chrome →
**校验渲染结果** → 截图 → 清理临时文件。全过程不需要手动干预。

> 复用说明：等前后端联调完成后，第 11、12 两张需要把「演示数据」换成真实接口调用再截一次，
> 其余 10 张不涉及后端，无需重做。
