# 截图清单（13 张）

> 助教作业帖要求博客提供「**10 张以上截图或 GIF / 视频**，每张配一句文字说明」。
> 本清单就是那份说明的来源，博客里可直接引用。
>
> **生成方式**：`node tools/capture-screens.mjs` —— 可复现，不是手点出来的。
>
> **这一版接了真实后端**：脚本会自己起一个真实的 Python 后端（用临时数据库），
> 页面真的调用后端计算、真的从数据库读历史。
> 所以每一张图里的结果都是**后端算出来的**，历史记录是**真存在数据库里的**。
>
> 每张截图在生成前都会校验页面确实渲染出了目标表达式**和**目标结果，
> 校验不通过就直接报错终止，因此不会出现"图与说明不符"的情况。

## 如何复现

```powershell
cd "D:\calss notes\软件工程\作业\计算器\832401217_calculator_frontend"
node tools\capture-screens.mjs
```

脚本自动完成：

1. 启动一个真实的 Python 后端（指定端口 + 临时数据库，用完即删）
2. 把 `src/` 复制到临时目录，把其中的后端地址改成临时后端的端口，**重新打包**
3. 启动无头 Chrome，为每张图开一个独立标签页
4. **真的用鼠标点击按键**（不是直接设状态），按 `=` 走真实 HTTP 请求
5. **校验**表达式与结果都对得上，然后截图
6. 清理：关掉浏览器与后端、删除临时文件

> 复现说明：脚本只在临时副本里改后端地址，**不会修改仓库里的 `src/`**。
> 跑完之后 `git status` 应该是干净的。
